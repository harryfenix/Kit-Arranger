Kit Arranger
Organize your Minecraft PvP kits quickly and safely! ⚔️🎒
Kit Arranger is a client-side Fabric mod that automatically arranges your inventory according to saved kit profiles.
Features
- ⚡ Automatically arrange your inventory
- 🛡️ Supports armor, hotbar, offhand, and inventory slots
- 🎯 BASIC and STRICT matching modes
- 🔍 Verifies item placement to prevent missed slots
- 📦 Works even when some kit items are missing
- 🔒 Lock your hotbar, armor, or offhand slots
- 💾 Save and manage multiple kit profiles
- 🌍 Global, single-player, and server-specific profiles
- 📋 Duplicate, delete, import, and export profiles
- ✅ Preview, progress messages, confirmation, and cancel options
- 🎨 Custom Kit Arranger logo
- 👑 Created by HARRY_FENIX
Controls
- P — Open Kit Dashboard
- K — Quick Arrange Inventory
You can change these keybinds from:
Options → Controls → Key Binds
Requirements
- Minecraft Fabric 1.21.11
- Fabric Loader
- Fabric API
This mod is client-side and does not need to be installed on the server.
Installation
1. Install Fabric Loader for Minecraft 1.21.11.
2. Install Fabric API.
3. Download the latest Kit Arranger .jar.
4. Place it inside your Minecraft mods folder.
5. Start Minecraft and open your inventory.
